## ☁️ Firebase Cloud Functions

### Созданные функции:

1. **`startDeliveryChain`** 
   - Запуск цепочки курьером
   - Проверка баланса
   - Проверка активных доставок
   - Отправка SMS первому клиенту

2. **`completeChainDelivery`**
   - Завершение текущей доставки
   - Расчет стоимости
   - Списание комиссии
   - Автозапуск следующей доставки
   - Отправка SMS клиенту

3. **`cancelDeliveryChain`**
   - Отмена цепочки курьером
   - Отмена всех незавершенных заказов

4. **`adminCreateDeliveryChain`**
   - Создание цепочки администратором
   - Назначение курьера
   - Push-уведомление курьеру
   - Отправка SMS первому клиенту

5. **`adminCancelDeliveryChain`**
   - Отмена цепочки администратором

6. **`adminCompleteDelivery`**
   - Принудительное завершение проблемной доставки

- ✅ `firebase/functions/src/index.ts` - добавлено ~600 строк кода с новыми функциями

## 📝 Примеры использования

### Сценарий 1: Курьер доставляет 3 заказа

1. Открывает "Дерево заказов"
2. Создает новую цепочку
3. Добавляет:
   - Заказ №1: +992901234567, ORD-101
   - Заказ №2: +992907654321, ORD-102
   - Заказ №3: +992909876543, ORD-103
4. Меняет порядок: 2 → 1 → 3
5. Запускает цепочку
6. Выполняет заказ №2 → автопереход к №1
7. Выполняет заказ №1 → автопереход к №3
8. Выполняет заказ №3 → цепочка завершена

**Результат:** 3 доставки за один выезд, экономия времени

### Сценарий 2: Администратор назначает срочную цепочку

1. Поступили 5 срочных заказов
2. Администратор открывает "Деревья заказов"
3. Создает цепочку
4. Добавляет все 5 заказов
5. Выбирает ближайшего свободного курьера
6. Назначает
7. Курьер получает push
8. Администратор отслеживает прогресс

**Результат:** Быстрое реагирование, контроль процесса
