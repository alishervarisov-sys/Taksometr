# Проверка подтверждения вручения на устройствах

Функциональность требует согласованного обновления Functions, правил Firestore,
админ-панели и Android. Само изменение исходников не обновляет опубликованный сервис.
Проверять на тестовых заказах; этот список не даёт разрешения создавать рабочие данные.

1. Создать заказ без переключателей: завершение и работа без интернета остаются
   прежними. Проверить обычный и фиксированный тарифы.
2. Создать заказ только с кодом, отдельно для выбранного курьера и свободный.
   Получатель получает шестизначный код в SMS после принятия заказа. Код не виден
   курьеру в полях заказа. Проверить поле кода в диалоге «Завершение заказа».
3. Ввести неверный код: заказ остаётся активным, комиссия не списывается,
   отслеживание продолжается. После пяти ошибок повтор возможен через пять минут.
4. Ввести правильный код: заказ завершается, в итоговом SMS есть код.
   В карточке администратора видно «Код получателя: Подтверждён».
5. Создать заказ только с фото: нельзя завершить до снимка. Проверить запуск
   камеры, отмену съёмки, пересъёмку, портретную и альбомную ориентации. Фото
   отправляется без EXIF/GPS и не больше 300 КБ. Администратор видит снимок.
6. Создать заказ с обоими требованиями: одно без другого не позволяет завершить.
   При ошибке кода снимок сохраняется для повторной попытки.
7. Повернуть устройство во время ввода кода и после съёмки: выбранные данные
   восстанавливаются. Проверить возвращение из камеры после пересоздания Activity.
8. Отключить интернет перед завершением и во время отправки: заказ с
   подтверждением остаётся активным до ответа сервера. После восстановления
   сети повторить; комиссия списывается один раз, даже если прежний ответ потерялся.
9. Попытаться завершить неподтверждённый заказ из админки: действие отклоняется.
   Отмена остаётся доступной. Для полученного подтверждения можно использовать
   существующие административные действия изменения статуса.
10. Проверить кнопку повторного SMS в карточке активного заказа: получатель
    получает тот же код; повтор чаще раза в минуту блокируется. Ошибка провайдера
    показывается администратору, не выдаётся за успешную отправку.
11. При двух активных заказах подтвердить текущий: отслеживание второго
    продолжается. При ошибке подтверждения текущего отслеживание не останавливается.
12. Обновить приложение поверх предыдущей версии: активные заказы, маршруты
    и очередь обычных завершений сохраняются при миграции Room 9 → 10.

Локальные сборки и эмулятор не подтверждают фактическую доставку SMS,
работу камеры конкретного телефона или поведение процесса Android после выгрузки.
