# Руководство по тестированию функции назначения курьера

## Предварительные требования

1. Firebase Functions развернуты:
   ```bash
   cd "c:\Users\alisher\Documents\Projic Flutter\Taksometr\ZaKiTaksometr\firebase"
   firebase deploy --only functions
   ```

2. Админ-панель пересобрана и развернута:
   ```bash
   cd "c:\Users\alisher\Documents\Projic Flutter\Taksometr\ZaKiTaksometr\admin-panel"
   npm run build
   ```

3. В Firestore есть:
   - Хотя бы один курьер с `isOnline = true` и `isBlocked = false`
   - Администратор с `role = 'ADMIN'`

## Сценарий 1: Успешное назначение

### Шаги:
1. Откройте админ-панель
2. Войдите как администратор
3. Перейдите на страницу "Курьеры"
4. Найдите курьера, у которого:
   - Статус = "Онлайн" (зеленый чип)
   - Не заблокирован
5. Нажмите на иконку **PersonAdd** (человек с плюсом) в колонке "Действия"
6. В модальном окне введите номер телефона:
   - Формат: `+992XXXXXXXXX` или `9XXXXXXXX`
   - Пример: `+992901234567` или `901234567`
7. Нажмите кнопку "Назначить"

### Ожидаемый результат:
- ✅ Модальное окно закрывается
- ✅ Появляется alert: "Курьер [Имя] назначен клиенту. SMS отправлено."
- ✅ Клиент получает SMS на таджикском языке с именем и телефоном курьера

### Проверка в Firestore:
1. Откройте Firebase Console → Firestore
2. Найдите коллекцию `courierAssignments`
3. Проверьте, что создан новый документ с полями:
   ```json
   {
     "adminId": "...",
     "courierId": "...",
     "courierName": "...",
     "clientPhone": "+992XXXXXXXXX",
     "createdAt": 1234567890
   }
   ```

### Проверка SMS:
1. Клиент должен получить SMS от "ZaKi"
2. Текст должен быть на таджикском языке
3. Содержимое:
   ```
   Расонандаи мо [Имя] (тел: [телефон]) барои шумо таъин карда шуд. 
   Барои фармоиш додан бо ӯ тамос гиред. 
   Барномаи ZaKi: https://clck.ru/3TuGb6
   ```

## Сценарий 2: Курьер заблокирован

### Шаги:
1. Выберите курьера со статусом "Заблокирован" (красный чип)
2. Нажмите на иконку **PersonAdd**
3. Введите номер телефона
4. Нажмите "Назначить"

### Ожидаемый результат:
- ❌ Ошибка: "Курьер заблокирован"
- ❌ SMS не отправляется

2. Нажмите на иконку **PersonAdd**
3. Введите номер телефона
4. Нажмите "Назначить"

### Ожидаемый результат:

## Сценарий 4: Пустой номер телефона

### Шаги:
1. Выберите любого онлайн курьера
2. Нажмите на иконку **PersonAdd**
3. Оставьте поле номера телефона пустым
4. Нажмите "Назначить"

### Ожидаемый результат:
- ❌ Ошибка: "Введите номер телефона клиента"
- ❌ SMS не отправляется

## Сценарий 5: Некорректный номер телефона

### Шаги:
1. Выберите онлайн курьера
2. Нажмите на иконку **PersonAdd**
3. Введите некорректный номер: `123` или `abc`
4. Нажмите "Назначить"

### Ожидаемый результат:
- ⚠️ Функция выполнится успешно, но SMS не отправится
- ⚠️ В логах Firebase: "SMS skipped: invalid phone number"

## Проверка логов Firebase

```bash
firebase functions:log
```

Ищите строки:
- `SMS sent to +992XXXXXXXXX, id=...` - успешная отправка
- `SMS skipped: invalid phone number "..."` - некорректный номер
- `Payom.tj SMS failed (...)` - ошибка от Payom.tj

## Отладка проблем

### Проблема: SMS не приходит

**Проверки:**
1. Убедитесь, что в `.env` файле правильно указан `PAYOM_API_TOKEN`
2. Проверьте, что функции развернуты с переменными окружения:
   ```bash
   firebase functions:config:get
   ```
3. Проверьте логи Firebase на ошибки от Payom.tj
4. Убедитесь, что номер телефона в формате `+992XXXXXXXXX` (12 цифр с кодом страны)

### Проблема: Модальное окно не открывается

**Проверки:**
1. Проверьте консоль браузера на ошибки JavaScript
2. Убедитесь, что импортирован `PersonAdd` из `@mui/icons-material`
3. Проверьте, что все состояния инициализированы

### Проблема: Ошибка "Only admins"

**Проверки:**
1. Убедитесь, что вы вошли как администратор
2. Проверьте в Firestore, что у пользователя `role = 'ADMIN'`
3. Убедитесь, что `adminId` передается правильно в компонент `Couriers`

## Дополнительная информация

### Формат номера телефона

Функция автоматически нормализует номер в формат `+992XXXXXXXXX`:
- `901234567` → `+992901234567`
- `0901234567` → `+992901234567`
- `+992901234567` → `+992901234567`
- `992901234567` → `+992901234567`
- `00992901234567` → `+992901234567`

### Стоимость SMS

Проверьте баланс в аккаунте Payom.tj, чтобы убедиться, что достаточно средств для отправки SMS.

### Лимиты

Payom.tj может иметь лимиты на количество SMS в минуту/час. Если отправляете много тестовых сообщений, возможны задержки.
