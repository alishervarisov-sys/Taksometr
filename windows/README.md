# ZaKi Dispatcher for Windows

Нативное WPF-приложение диспетчера, которое работает **параллельно** с существующей веб-админкой.

## Два режима работы

1. **Полная панель** — локально встроена текущая React-админка. Доступны все
   разделы и все функции веб-версии: Dashboard, курьеры, победитель месяца,
   доставки, клиенты, тарифы, комиссия, логины, админы, карта, трекинг,
   статистика, аналитика, Telegram-отчёт, TAXI, таксисты и версии.
2. **Локальные заказы** — отдельный нативный WPF-экран для быстрого просмотра,
   поиска и смены статуса даже при нестабильной сети.

Данные заказов дополнительно хранятся в SQLite по адресу
`%LOCALAPPDATA%\ZaKi\Dispatcher\zaki-dispatcher.db`. Firestore-кэш полной
панели сохраняется в профиле WebView2. Фоновая синхронизация SQLite выполняется
каждые 15 секунд, а неподтверждённые смены статуса остаются в очереди до
восстановления соединения.

Веб-панель в `admin-panel/` не изменяется и продолжает работать независимо.

## Уведомления о пополнении (версия 1.3.0)

ZaKi проверяет новые заявки каждые 15 секунд и показывает системное уведомление
Windows с кнопкой «Открыть заявку». Кнопка открывает нужную заявку в разделе
«Комиссия», где администратор выбирает «Долг» или «Оплачено» и одобряет её.
После решения уведомление убирается. Уже показанные заявки не повторяются
после перезапуска приложения.

Закрытие окна оставляет приложение в фоне рядом с часами. Через значок ZaKi
можно открыть панель, проверить уведомления или полностью выйти. В установщике
есть автозапуск в фоне при входе в Windows. Для доставки уведомлений нужен
интернет и работающий фоновый процесс. После полного «Выхода», выхода из
аккаунта или выключения компьютера уведомления не доставляются.

Если Windows отключила уведомления ZaKi, включите их в системных настройках.
Кнопка «Проверить уведомления» в приложении показывает проверочное уведомление.

[Скачать установщик Windows 1.3.0](https://zakitaksometr.web.app/downloads/ZaKi-Admin-Windows-Setup-1.3.0.exe).
Для обновления запустите установщик на компьютере администратора.

## Сборка

```powershell
dotnet restore .\windows\ZaKi.Dispatcher\ZaKi.Dispatcher.csproj
dotnet build .\windows\ZaKi.Dispatcher\ZaKi.Dispatcher.csproj -c Release
```

## Установка на компьютер

Для выдачи пользователю создаётся обычный установщик Windows: он устанавливает
приложение в `Program Files`, добавляет пункт меню «Пуск», ярлык (по выбору) и
удаление через системные настройки.

```powershell
.\windows\build-installer.ps1
```

Для создания установщика на компьютере разработчика должен быть установлен
Inno Setup 6 или 7. Готовый `ZaKi-Admin-Windows-Setup-*.exe` появится в
`windows\release\installer\`.

Для первого входа и операций Cloud Functions нужен интернет. Ранее загруженные
экраны Firestore и нативный список заказов доступны из локальных кэшей.
